# 写作规则（默认）

每条 = 一张论证图（ARGMAP.md）+ 正文。按内容量写，通常 200–1,500 字。

- 先读完原文再写；转述类素材追到源头。数字、条件、限定照原文，不编、不加强。
- 开头两句交代这是什么、解决什么问题、跟什么有关；结尾给后果，不列清单。
- 一句只做一件事。
- 正文不能有 Markdown（X 原样显示符号）：只用纯文本、数字编号和空行分段。
- 正文里不放任何链接（带站外链接的帖子会被 X 降权）。正文末尾一句「原文链接在评论区」，再一行 2–3 个话题标签。
- 原文链接写进首条回复：`原文：<URL>`（几条素材就逐行列出）。发布时它紧跟在帖子下面发出。

一个内容工作室可以在自己的配置目录（DNA_CONFIG_DIR）里放 writer/RULES.md 覆盖这份默认规则；
writer/ARGMAP.md 同理。
